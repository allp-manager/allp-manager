# پرسش‌های پرتکرار

[← خانه ویکی](Home.fa.md) · [English](FAQ.md)

**آیا Allp یک Package Manager جدید است؟** خیر؛ ابزار Native نصب‌شده را هماهنگ
می‌کند و Dependency Resolver یا دیتابیس جهانی ندارد.

**دستور Native را پنهان می‌کند؟** خیر؛ Argv، Source، Scope و Privilege تغییر
قبل از تأیید نمایش داده می‌شوند.

**باید `sudo allp` اجرا کنم؟** معمولاً خیر؛ با کاربر عادی اجرا کنید تا فقط Child
نیازمند Root ارتقا پیدا کند.

**Update و Upgrade یکی هستند؟** خیر؛ Backend معنا را تعیین می‌کند. معمولاً اولی
Metadata و دومی نرم‌افزار نصب‌شده را تغییر می‌دهد.

**آیا `--yes` همه چیز را قبول می‌کند؟** خیر؛ فقط تأیید نهایی Allp را رد می‌کند.
منبع مبهم و Bootstrap همچنان صریح هستند.

**Profile نسخه دقیق را بازسازی می‌کند؟** فعلاً خیر؛ Format نسخه ۱ فقط Version
مشاهده‌شده را ثبت می‌کند و Pin نیست.

**Lockfile پروژه تغییر می‌کند؟** نگهداری Host در Cargo هرگز چنین کاری نمی‌کند.
عملیات پروژه Python/Node به Target/Scope صریح نیاز دارد و محافظه‌کار است.

**برای Production سخت‌سازی شده؟** پروژه Public Alpha و بدون ممیزی امنیتی است.
